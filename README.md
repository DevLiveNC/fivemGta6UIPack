# liveBase UI Pack

GTA VI bağlamsal HUD dilinden esinlenen, liveBase’e özgü FiveM/QBCore NUI paketi.

- Gündüz fildişi `#F4F2EB`, gece mürekkep `#141923`, deniz `#236E76`, kehribar `#E9A94B`, mercan `#DE6657`
- HUD, araç telemetrisi, telefon, tetris envanter, hızlı seçim, harita, görev günlüğü, NPC, radyo, garaj, yarış, admin
- React + TypeScript + Vite · Lua NUI köprüsü · sürümlü mesaj `{ v: 1, type, payload }`

```bash
npm install
npm run dev      # tarayıcı önizleme
npm run build    # dist/ → fxmanifest ui_page
npm run typecheck
```
